The problem

Your AI assistant is great at planning.
It runs out of room the moment work gets long.

In the chat today
  • Multi-hour audits run inline and burn the context window.
  • A deep-research sweep blocks every other tool call.
  • Close the laptop and the run dies.
  • Parallel work is sequential by default.
  • Tools cap at what the local process can reach.
With AgentDispatch
  • Long work moves to a managed cloud worker.
  • One MCP call returns a task_id — chat keeps moving.
  • Runs survive disconnects. Pick up the result later.
  • Fan out a fleet in parallel; aggregate in chat.
  • Cloud-side tools, credentials, and compute the laptop never sees.

How it works

A single tool. A small contract. A real cloud.

01

Your assistant calls one tool

Claude Code, OpenClaw, Hermes — any MCP client — calls spawn_cloud_agent with an instruction.

02

AgentDispatch routes the work

The dispatcher resolves a runtime profile, persists a task, and invokes the right adapter for your cloud.

03

A real cloud agent runs

The worker runs on managed compute (AWS Bedrock AgentCore today) — for seconds, minutes, or hours.

04

You collect the result

Status, paginated logs, and the final payload all stream back through the same MCP channel.

Install

Three faces. One runtime.

Pick the entry point that fits — they all talk to the same dispatcher.

$ npm install @agent-dispatch/core @agent-dispatch/mcp-server \
    @agent-dispatch/store-sqlite @agent-dispatch/adapter-aws-agentcore

$ npx agentdispatch-mcp --config agentdispatch.config.json --check
// Claude Code · OpenClaw · Hermes · any MCP client
{
  "mcpServers": {
    "agentdispatch": {
      "command": "npx",
      "args": ["agentdispatch-mcp", "--config", "/abs/path/agentdispatch.config.json"]
    }
  }
}
$ npm install @agent-dispatch/sdk @agent-dispatch/core
import { createClient } from "@agent-dispatch/sdk";

const client = createClient({ configPath: "agentdispatch.config.json" });

const { taskId } = await client.spawnCloudAgent({
  instruction: "Audit every Lambda for public invoke.",
  runtime: "security-agent"
});

for await (const event of client.streamTask(taskId)) console.log(event);
$ npm install -g @agent-dispatch/cli

$ agentdispatch check --config agentdispatch.config.json
$ agentdispatch spawn "Investigate this stack trace across all services."
$ agentdispatch logs <task-id> --follow
$ agentdispatch result <task-id>

The stack

Nine small packages. One focused job each.

mcp-server Entry point

The MCP face. Hand it to Claude Code, OpenClaw, or Hermes.
core

Runtime contracts and the dispatch loop.
sdk-js

Typed TypeScript SDK for application code.
cli

Spawn, inspect, and cancel agents from the terminal.
store-sqlite

Default SQLite + filesystem state store.
adapter-aws-agentcore

AWS Bedrock AgentCore adapter.
worker-agentcore

Standard AgentCore worker contract.
adapter-template

Starter scaffolding for new cloud adapters.
docs

Guides, architecture, and reference.
